# 🎓 EduHub – Online Learning Platform

EduHub is a web-based Online Learning Platform frontend built with **React.js** and **Firebase**. It provides a user-friendly interface with authentication, navigation, and different pages to support an online learning experience.

## 🚀 Technologies Used

- **React.js** – Frontend library
- **JavaScript (JSX)** – Application development
- **CSS3** – Styling and layout
- **Firebase** – Authentication and backend integration
- **React Router** – Application navigation and routing
- **HTML5** – Web structure

## ✨ Features

- 🔐 User Authentication with Firebase
- 🧭 Navigation bar for easy navigation
- 📄 Multiple application pages
- 🔄 Client-side routing
- 🎨 Interactive user interface
- 📱 Online learning platform interface
- 🔥 Firebase integration

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd your-project-folder
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure Firebase**

Set up your Firebase project and configure its credentials in your Firebase configuration file.

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 🔥 Firebase Integration

Firebase is integrated into the project for user authentication and related backend functionality.

Make sure to configure your own Firebase project credentials before running the application.
